# Pacific View Window Configurator v0.2

React + Vite touch-first prototype.

## Features

- Draw vertical splits with your finger
- Draw horizontal splits with your finger
- Select panels
- Drag mullions
- Change panel type
- Casement, awning, and slider opening symbols
- Basic grids
- Live dimensions
- Save to the device browser
- Undo and clear

## GitHub upload

Delete the old prototype files, then upload the complete contents of this ZIP to the root of your repository.

## Vercel settings

Vercel should detect Vite automatically.

- Framework preset: Vite
- Build command: npm run build
- Output directory: dist
